# CAFESTO - Food Ordering App

**Tech Stack**: React | Spring Boot | Firebase | Stripe | SQL | JWT

## 📌 Project Overview

CAFESTO is a **responsive food ordering web application** designed to provide a seamless experience for customers and restaurant owners alike. Users can browse menus, place orders, and track them in real-time. The application supports secure authentication and payment methods, making it an end-to-end solution for online food ordering.

## 🚀 Features

- ✅ **Responsive Design** – Works smoothly across desktops, tablets, and mobile devices.
- ✅ **Authentication** – Google & Facebook sign-ins powered by Firebase Authentication.
- ✅ **Payment Integration** – Secure and smooth payments via Stripe.
- ✅ **Real-Time Order Tracking** – Customers can track their orders as they progress.
- ✅ **JWT-Based Authentication** – Secure backend communication with JWT tokens.
- ✅ **SQL Database** – Structured data storage for menus, orders, and users.
- ✅ **Spring Boot Backend** – Handles business logic, REST APIs, and order management.

## 🧱 Tech Stack

- Frontend: React
- Backend: Spring Boot
- Authentication: Firebase (Google & Facebook sign-in)
- Payment Processing: Stripe
- Database: SQL (MySQL/PostgreSQL)
- Security: JWT (JSON Web Tokens)

## 🔧 Installation

### 1. Backend Setup
```bash
cd backend
./mvnw spring-boot:run
```
### 2. Frontend Setup
```
cd front-end
npm install
npm start
```
